# WebMaster TOC

Зміст статті за заголовками H2 для WordPress з класичним редактором.

- Автоматично перед першим H2, якщо в статті достатньо H2 і тексту, або в місці мітки `[wm_toc]`.
- Кнопки «TOC» (вставити мітку) і «Без TOC» (вимкнути зміст у статті) у панелі візуального редактора.
- Статус змісту в нижній смузі редактора.
- Налаштування: Налаштування → WebMaster TOC.

## Оновлення

Плагін перевіряє GitHub Releases цього репозиторію. Новий реліз:

1. Змінити `Version:` і `WMTOC_VERSION` у `webmaster-toc.php`, додати запис у `CHANGELOG.md`, закомітити.
2. Releases → Draft a new release → тег `vX.Y` (той самий номер) → опис з CHANGELOG → Publish.
3. Сайти побачать оновлення протягом 12 годин або одразу після «Перевірити оновлення».
